# Multi-Market Onboarding Kit

An independent proposal by Shorouk for how Factorial could run customer onboarding as one shared model across every market, with a short local module for what changes in each country.

**Live page:** https://shorouk9.github.io/factorial-onboarding-kit/

## What's inside

- **The core path**: five stages from signature to handover, with owners, tasks, exit criteria and target days for small, mid and large customers.
- **Sales-to-onboarding handoff check**: an interactive scorecard that says whether a deal is ready for onboarding, with a copyable summary.
- **Market modules**: Spain, Germany, France, Italy, Portugal, UK, Brazil, Mexico and the UAE — payroll, compliance topics, common blockers and kickoff questions.
- **Time-to-value tracker**: log onboardings, see days to go-live against target and compare markets. Data stays in the visitor's browser; export and import as CSV.
- **Team rhythm and measures.**
